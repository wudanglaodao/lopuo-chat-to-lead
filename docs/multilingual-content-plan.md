# 多语言内容与 AI 翻译计划

版本：v0.1
日期：2026-05-13
关联文档：[AI 客服助手 PRD](./ai-customer-service-prd.md)、[客户独立服务计划](./customer-dedicated-service-plan.md)

## 1. 目标

后续让同一个企业、同一个租户的知识库支持多语言服务：

- 访客用中文、英文或其他语言提问时，AI 能用访客语言回答。
- Widget 固定文案、欢迎语、推荐问题和留资表单支持多语言。
- 官网知识库可以保留原文，同时生成目标语言译文和向量索引。
- 重点商务内容可由人工复核，避免机器翻译误改价格、承诺和法律含义。

## 2. 推荐策略

第一阶段采用“AI 翻译 + 缓存 + 人工复核”的混合方案。

不建议每次访客提问时临时翻译整段知识库，因为延迟高、成本不稳定，也难以审计。更适合在知识库同步后做离线翻译：抓取原文后，按目标语言生成译文、切块、向量化，并记录翻译状态。

## 3. 语言层级

### 3.1 Widget UI 语言

- 支持 `data-locale`，例如 `zh-CN`、`en-US`、`ja-JP`。
- 未传时自动检测浏览器语言。
- 固定按钮、输入框、错误提示、留资字段走前端 i18n 字典。
- 欢迎语和推荐问题从后台按 locale 配置。

### 3.2 知识库内容语言

- 每个租户可开启多个目标语言。
- 知识来源记录原始语言，例如官网中文内容为 `zh-CN`。
- 同步后为启用语言生成翻译版本，例如 `en-US`。
- 每个 chunk 记录 `locale`、`source_locale`、`translation_status` 和 `translated_from_chunk_id`。

### 3.3 AI 回答语言

- 先检测用户问题语言。
- 优先检索同语言知识片段。
- 如果同语言内容不足，再回退到原文知识片段，并让模型用访客语言总结回答。
- 回答中保留来源链接，来源可标记“机器翻译”或“原文”。

## 4. 后台能力

后台后续增加“多语言”配置区：

- 默认语言。
- 启用语言列表。
- 术语表/品牌词表，例如公司名、产品名、行业术语不翻译或固定翻译。
- 每个语言的欢迎语、推荐问题和留资字段文案。
- 知识库翻译状态：待翻译、翻译中、待复核、已发布、失败。
- 单条来源或单个租户的重新翻译入口。

## 5. 数据模型待办

建议新增或扩展：

- `sites.default_locale`
- `sites.enabled_locales`
- `sites.widget_i18n`
- `tenants.default_locale`
- `tenant_locales`
- `knowledge_sources.source_locale`
- `knowledge_chunks.locale`
- `knowledge_chunks.source_locale`
- `knowledge_chunks.translation_status`
- `knowledge_chunks.translated_from_chunk_id`
- `translation_jobs`
- `translation_glossary_terms`

`translation_jobs` 用于记录翻译任务状态、模型、成本、失败原因和重试次数。

## 6. RAG 流程待办

1. 用户打开 Widget 时确定 locale。
2. 创建会话时写入 `locale`。
3. 用户提问时检测语言。
4. 向量检索时增加 `tenant_id + locale` 过滤。
5. 同语言低命中时允许回退到默认语言。
6. Prompt 中要求回答语言与用户语言一致。
7. 消息记录中保存 `detected_locale`、`answer_locale` 和是否使用回退语言。

## 7. AI 翻译流程待办

1. 知识库同步完成后触发翻译任务。
2. 翻译前套用术语表和禁止翻译词。
3. 翻译后做基础质量检查：空译文、长度异常、URL/数字/价格丢失。
4. 重点页面进入人工复核队列。
5. 通过复核后再生成目标语言 embedding。
6. 保留原文和译文版本，方便重新翻译和回滚。

## 8. 安全边界

- 价格、合同、交付承诺、法律条款等内容默认需要人工复核后发布多语言版本。
- AI 翻译不得改变金额、日期、限制条件和免责声明。
- 当翻译内容未复核时，回答应避免使用确定性承诺。
- 后台需要标记机器翻译内容和最后复核人。

## 9. 开发阶段

### 阶段 A：语言字段预留

- 给站点、租户、会话、消息和知识块预留 locale 字段。
- Widget 支持 `data-locale`。
- 前端固定文案接入 i18n 字典。

### 阶段 B：后台配置

- 设置页增加多语言配置。
- 支持每个语言配置欢迎语和推荐问题。
- 会话列表展示访客语言。

### 阶段 C：翻译任务

- 增加 `translation_jobs`。
- 知识库同步后自动生成翻译任务。
- 支持手动重试和查看失败原因。

### 阶段 D：多语言 RAG

- 检索增加 locale 过滤和默认语言回退。
- 回答语言跟随访客语言。
- 来源显示原文/译文状态。

### 阶段 E：人工复核与质量

- 增加术语表。
- 增加复核状态。
- 对重点页面启用人工批准后发布。
